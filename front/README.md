# Бизнес кабинет — фронтенд

Прототип «умного кабинета предпринимателя»: React 18 + TypeScript + Vite + React Router.
Объединяет две версии интерфейса: структуру и функциональность из `frontend/` и визуал из первой версии `front/`.

## Запуск

Нужен Node.js 22.18+ (проверка: `node -v`).

```bash
cd front
npm install
npm run dev        # http://localhost:5173
npm run build      # проверка типов + сборка в dist/
npm test           # расчёты и проверка реквизитов
```

На Windows в PowerShell используйте `npm.cmd` вместо `npm`, если политика выполнения скриптов блокирует `npm`.

Вход — любой логин и пароль или «Демо-вход». Параметр `?demo` в адресе сразу открывает кабинет.
Шрифт Inter подключён локально (`@fontsource/inter`): после `npm install` приложение не обращается к внешним ресурсам.

## Клиентский путь

**Выбор цели → параметры → проверка/дозагрузка → выдача.** На каждом экране заявки видно, на каком этапе она находится и что требуется от клиента.

| Маршрут | Экран |
| --- | --- |
| `/` | Главная: текущая заявка с этапами и следующим шагом, другие заявки, компания |
| `/profile` | Личный кабинет: профиль, текущая заявка, реквизиты (ИНН, ОГРН) |
| `/financing` | «На что нужны деньги?» — цели, незавершённые черновики, «Рассчитать условия» |
| `/financing/calculator` | Мастер: условия (калькулятор) → компания → данные → проверка |
| `/applications` | Мои заявки: вкладки по состояниям, даты, этап, следующий шаг |
| `/applications/:id` | Заявка: условия и ставка, этапы, документы с дозагрузкой, история, график |
| `/help` | Альфа-помощник: чат, быстрые вопросы, загрузка выписки, оператор |

Тёмное меню «Следующий шаг для вашего бизнеса» открывается при наведении на «Финансирование» в сайдбаре.

## Стейт-машина заявки

```
DRAFT → SUBMITTED → MANUAL_REVIEW ⇄ NEED_INFO
                         ├→ APPROVED ─────────→ (условия приняты, кредит выдан)
                         └→ COUNTER_OFFER → APPROVED
```

- Переходы описаны в `src/store/data.ts` (`TRANSITIONS`). Редьюсер отклоняет недопустимые.
- `SUBMITTED → MANUAL_REVIEW` происходит автоматически через несколько секунд (имитация backend).
- Дозагрузка документов в `NEED_INFO` возвращает заявку в `MANUAL_REVIEW`.
- На странице заявки есть панель «Демо: ответ банка» — она двигает заявку по остальным переходам вместо backend.

## Расчёт

Аннуитетные платежи по условной ставке 18% годовых без комиссий (`src/utils/finance.ts`).
График — с точностью до копеек, последний платёж корректируется до полного погашения.
Сумма — от 500 тыс. до 5 млн ₽ с шагом 50 тыс., срок — от 6 до 36 месяцев. Значения меняются ползунками, быстрыми суммами или вводом числа по клику.

## Демо-данные

Заявки, черновик мастера и чат хранятся в `localStorage` этого браузера. Файлы никуда не отправляются: сохраняются только имя и размер.
Сброс: «Личный кабинет» → «Сбросить демо-данные».

## Структура

```
src/
  art/          SVG: коты-маскоты, плавные ленты, изометрические иллюстрации целей
  components/   каркас (Sidebar, Topbar, Layout), статусы и этапы, ползунок, загрузка, график
  pages/        экраны
  store/        состояние (useReducer + localStorage), стейт-машина, демо-данные, ответы бота
  styles/       токены и базовые стили, каркас, страницы, мастер, чат
  utils/        расчёт кредита, проверка реквизитов, форматирование
```

## Подключение backend

Точки замены: `store/bot.ts` (ответы помощника), действия `wizard/submit`, `app/addDocuments`, `app/accept`, `app/transition` в `store/store.tsx` (отправка, документы, решения банка), автопереход `SUBMITTED → MANUAL_REVIEW` в `StoreProvider`.
