# Бизнес кабинет

Готовый фронтенд React + Vite для хакатона. Сначала распакуйте архив в обычную папку, затем откройте **эту папку** в VS Code. Внутри должен быть файл `package.json`.

## Запуск на Windows

1. В VS Code выберите «Файл → Открыть папку» и откройте `business-cabinet`.
2. Выберите «Терминал → Создать терминал».
3. Выполните последовательно:

```powershell
npm.cmd install
npm.cmd run dev
```

4. Откройте адрес из терминала — обычно http://127.0.0.1:5173/.
5. Нажмите «Демо-вход». Либо введите любой вымышленный логин и любой демо-пароль.

`npm.cmd` работает в Windows PowerShell без изменения политики выполнения скриптов. В CMD также можно использовать `npm`. На macOS/Linux используйте `npm install` и `npm run dev`.

Нужен Node.js 20.19+ (например, 22 или 24). Проверка: `node -v`. Первый `npm.cmd install` требует интернет. После установки обычный запуск не обращается к внешним API, шрифтам или изображениям.

Сервер должен оставаться запущенным в терминале. Для остановки нажмите Ctrl+C. Чтобы открыть снова — `npm.cmd run dev`.

## Что реализовано

- Вход в демо-режиме и выход.
- Главная с текущей заявкой и её статусом.
- Три цели финансирования, красная лента, тёмная навигация и раскрывающаяся панель.
- Калькулятор: сумма от 500 тыс. до 5 млн ₽; срок 6–36 месяцев. Ползунки с котиками, быстрые суммы и ручной ввод по клику на число.
- Аннуитетный расчёт с условной ставкой 18% годовых; согласованные платёж, переплата и полная сумма выплат. Подробный график с точностью до копеек.
- Анкета: условия → компания → финансовые данные → проверка. Проверка обязательных полей и длины ИНН/ОГРН/ОГРНИП (без реестров и контрольных сумм).
- Демо-заполнение компании, загрузка локальных документов и кнопка демо-выписки.
- Создание заявки и добавление в «Мои заявки».
- Фильтры, детали, документы, история и график заявки.
- Добавление документов к заявке «Нужны документы», смена демо-статуса на рассмотрение.
- Просмотр и принятие демо-предложения.
- Личный кабинет справа сверху: ФИО, текущая заявка, реквизиты компании.
- Чат: демонстрационные ответы, быстрые вопросы, локальные вложения и честное обозначение имитации оператора.
- Уведомления по демо-событиям.

## Как пройти полный сценарий

1. Нажмите «Демо-вход».
2. «Финансирование» → выберите цель → «Рассчитать условия».
3. Настройте сумму и срок; откройте график при необходимости.
4. «Продолжить» → «Заполнить демо» → «Продолжить».
5. «Использовать демо-выписку» → «Продолжить».
6. Отметьте подтверждение → «Отправить заявку».
7. Новая заявка появится в списке со статусом «На рассмотрении».

## Сохранение демо-данных

Заявки, черновик, сообщения и факт демо-входа хранятся в localStorage этого браузера. Пароль не сохраняется. Используйте вымышленные сведения: шифрование и настоящая авторизация пока отсутствуют.

Документы не отправляются и не сохраняются как файлы: в прототипе остаются только названия и размеры. После обновления страницы нельзя открыть содержимое выбранного документа. Помощник не анализирует файлы.

Чтобы сбросить демо, откройте инструменты разработчика браузера (F12) → Application / Приложение → Local Storage → адрес приложения. Удалите только ключи с префиксом `bc-` и обновите страницу. Выход из кабинета не удаляет заявки и черновик.

## Файлы

- `src/App.jsx` — экраны, навигация, анкета, список заявок, профиль, чат.
- `src/styles.css` — оформление, размеры, сетка, цвета.
- `src/components/Art.jsx` — SVG-иконки, красная лента, иллюстрации целей и котик. Собственная векторная интерпретация макетов; не официальный набор иллюстраций банка.
- `src/finance.js` — расчёты, форматирование, проверка полей.
- `src/api.js` — демонстрационный адаптер чата для дальнейшего подключения backend.
- `src/finance.test.js` — проверки расчётов и реквизитов.
- `public/favicon.svg` — иконка вкладки.

Дизайн ориентирован на компьютер: 1280–1920 px. Минимальная ширина — 1000 px. Мобильная версия пока не разработана.

## Проверки и сборка

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run preview
```

Готовая сборка находится в `dist`. Не открывайте `index.html` двойным кликом — используйте сервер Vite.

## Подключение backend

На этом этапе backend не нужен. Настоящие вход, получение реестров, загрузка документов, рассмотрение заявок, оператор и Госуслуги не подключены. Демо-данные и подсказки прямо отмечают это в интерфейсе.

После согласования API можно заменить реализацию `src/api.js`, подключить авторизацию, загрузку файлов, хранение заявок и чат, затем заменить локальные операции в App.jsx запросами к API. Сам по себе этот прототип не является готовым интегрированным клиентом backend.
